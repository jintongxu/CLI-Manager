# 独立对话问题大纲与点击定位

## 目标

在独立 AI 对话的当前会话消息区，按时间顺序列出用户发出的提问，点击提问定位到该条消息。大纲仅从当前已加载的消息生成，不生成模型摘要、不修改数据库或网络协议。

## 场景与约束

- 空会话不展示伪问题；切换/新建/删除会话时大纲同步切换，不能引用上一会话 DOM。
- 长问题使用首个非空行摘要并截断显示，完整内容可通过 title 查看；排序与消息一致。
- 点击使用当前消息滚动容器定位并设置高亮；用户手动滚动时高亮跟随可见提问；键盘按钮可激活。
- 默认只露出消息区右缘的细入口，不长期占用正文宽度；鼠标移到边缘时浮出大纲、离开后收起，键盘聚焦也能打开，按钮可固定展开。宽窄窗口均不覆盖输入框。
- 多窗口/分屏、窗口失焦/最小化、无模型、后台生成、尚未加载消息、主题及中英文都应安全；不碰终端/BTW/WSL/hook/Worktree 逻辑。
- 保留既有工作区未提交改动；不新增依赖或后端持久化，不改变会话流与草稿生命周期。

## 验收

- [ ] 当前会话的每条用户消息在大纲中恰好出现一次；空会话不显示条目，切换会话不会残留旧条目。
- [ ] 点击或键盘激活大纲项后定位对应用户消息；手动滚动更新大纲的当前项。
- [ ] 默认大纲收起，仅保留边缘入口；鼠标靠近/键盘聚焦时显示，离开收起，不挤占消息正文或输入框；长文本不会撑开布局，中英界面可用。
- [ ] 定向组件/交互测试与 TypeScript 检查通过；架构检查不新增超限。

## 工作区保护

本任务沿用现有分支与已存在的未提交聊天改动；不执行 Git 同步、提交、清理或关闭其它应用进程。
