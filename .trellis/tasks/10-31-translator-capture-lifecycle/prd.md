# 修复截图翻译全屏遮罩阻塞与窗口生命周期

## 优先级与安全限制
P0：截图翻译可能创建不可交互的全屏透明置顶窗口，阻塞桌面鼠标输入。已停止本次开发进程。未经安全验证不启动真实全屏截图，不自动重启开发版。

## 用户需求
截图快捷键应快速进入可取消的框选；无论前端加载、截图、翻译是否失败，都不能留下拦截桌面输入的空白窗口。保留已有输入翻译功能，不扩大到模型路由、提示词或视觉重设计。

## 初步根因（待当前代码验证）
Rust 原生窗口显示生命周期与前端取帧生命周期不一致：隐藏窗口预热时前端已经挂载并执行唯一一次取帧，后续显示窗口没有触发新帧消费；后端不等待可交互确认即显示全屏置顶窗口。修复必须落在原生/前端截图会话边界，而非单独给空白 UI 打补丁。

## 发现清单与调查范围
- `src-tauri/src/features/translator/window.rs`：预热、显示、隐藏及窗口焦点/关闭行为。
- `src-tauri/src/features/translator/capture.rs`：冻结帧槽位、取帧权限、IPC 与取消。
- `src-tauri/src/features/translator/shortcuts.rs`：快捷键入口、并发触发与后台抓屏。
- `src-tauri/src/lib.rs`：启动预热与命令注册。
- `src/features/translator/api/CaptureWindowApp.tsx`：订阅/就绪、每次取帧、翻译与异常退出。
- `src/features/translator/components/ScreenshotOverlay.tsx`：图片加载、Esc、取消与确认。
- `src/features/translator/api/TranslatorWindowApp.tsx`：结果交接与旧请求隔离。
- `scripts/translator.test.mjs` 及对应 Rust 单元测试：实际状态转换与故障注入；不能仅靠字符串断言证明生命周期安全。
- `src-tauri/capabilities/default.json`：核对最小窗口权限。
- `CHANGELOG.md`、`docs/功能清单.md`：记录实测结果，不宣称未经测量的性能收益。

GitNexus CLI 入口 `.gitnexus/run.cjs` 当前缺失；按分诊文档使用契约和符号搜索补齐触点，不能将空调用图视为低风险。

## 必须覆盖的场景
1. 冷启动、预热隐藏、首次截图、连续多次截图。
2. 主窗口前台/后台/最小化或托盘；截图前已有翻译浮窗。
3. 连续按快捷键、取消后重开、上一轮抓屏/翻译迟到。
4. 前端未就绪、事件未送达、图片解码失败、IPC/抓屏失败。
5. Esc、取消、焦点丢失、关闭、窗口销毁及翻译超时。
6. 多屏、负坐标、不同 DPI；截图不能包含自身遮罩。
7. 模型失败不能被当作成功译文，不能继续占用全屏输入。

## 验收标准
- 每次截图有独立身份；过期结果或确认不能打开/关闭/覆盖新会话。
- 未完成前端取帧、图片加载和交互准备时，窗口保持隐藏；不存在空白全屏吞点击状态。
- 已预热窗口每次重开均取得对应新帧；无权限错误的兜底现抓屏。
- Esc/取消可退出；前端失效时原生层仍有有界释放途径，并有定向故障测试。
- 取消后抓屏、翻译迟到都不会重新显示遮罩或结果窗口。
- 先在不显示真实全屏窗口的隔离测试中验证状态机及故障；真人桌面验证需明确告知安全措施。
- 运行最小相关前后端测试、类型检查和独立严格架构检查；如架构检查存在无关超限，准确报告而非宣称通过。
