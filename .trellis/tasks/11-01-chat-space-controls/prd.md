# 对话空间交互优化与会话置顶

## 目标

1. 新/未设置推理强度的对话默认选「中」；用户仍能选择其他等级或“不指定”，切换对话后按会话恢复。
2. 标题栏「项目 / 对话」改为轻量导航，摆脱拥挤的嵌套描边分段块，明确选中态；macOS 原生交通灯区域可用。
3. 对话历史支持置顶/取消置顶，置顶条目排在普通条目前并显示明确标识；拖动排序、搜索/分页、重载、删除后顺序保持正确。
4. 左侧对话历史栏可收起/展开，收起后消息区域扩展且入口始终可达；无对话时也能重新展开。

## 场景

- 新旧会话、明确“不指定”与无保存值；多会话切换、应用重载；只改前端选项默认，不改变已有生成请求契约。
- 历史列表有无搜索过滤/下一页；置顶、取消置顶、重排、删除；本地持久化与无法写入存储时本次窗口内可用。
- 项目/对话切换、无历史/未选中会话、窄窗口、隐藏/展开、焦点和键盘导航；不改终端/BTW/Worktree/WSL/hooks 生命周期。
- 主题和 zh-CN/en-US 文案；保留未提交代码、数据、进程；不引入数据库迁移或新依赖。

## 验收

- [ ] 无保存值时推理强度为「中」；明确选择不指定仍可保存并恢复。
- [ ] 置顶与取消置顶可从右键菜单操作，置顶条目有图标和状态，重载顺序稳定。
- [ ] 侧栏收起后内容占满空间且始终可展开，正常操作不打断会话或生成。
- [ ] 标题栏控件更轻量、可见选中态和焦点态；测试/类型/架构检查不新增问题。
