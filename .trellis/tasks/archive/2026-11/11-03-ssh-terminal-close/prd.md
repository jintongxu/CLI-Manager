# SSH 终端关闭语义修复

## 需求
SSH 项目和独立 SSH Shell 执行关闭时，断开并移除会话，而非仅隐藏；系统资源列表不再保留此次关闭的会话。

## 边界
保留本地/WSL 默认隐藏、显式隐藏、取消确认、当前工作保护、远程交接锁定。不得自动清扫已有隐藏会话或通过资源列表过滤掩盖存活连接。

## 验收
- SSH 各连接状态、单个/批量/分屏关闭进入严格后端关闭。
- 后端关闭失败保留会话以便重试；混合批次按会话分派。
- 明确隐藏及切换焦点/窗口/项目不销毁 SSH。
- 定向测试、TypeScript、严格架构检查通过；真实 SSH 手动验收如无环境需明确未完成。
- CHANGELOG TEMP 与功能清单同步更新，不改变发行版本号。
