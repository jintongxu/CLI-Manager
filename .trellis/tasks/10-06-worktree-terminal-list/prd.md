# Worktree 终端列表与标签隐藏

## Goal

项目侧栏 Worktree 下显示所属终端；标签关闭仅隐藏，列表右键删除才彻底删除。

## Requirements

- 普通 PTY 标签关闭后继续运行，终端列表保留；点击原条目重开同一终端，不创建进程。
- 隐藏条目与归属在应用重启的现有会话恢复流程中保留；遵循恢复总开关、ask/auto、daemon 优先与 CLI resume，不保证不存在的进程跨重启续跑。
- Worktree 列表按 worktreeId 归属，主仓库终端在项目下可达；显示标题及状态，支持键盘与右键删除。
- 所有标签关闭入口包括批量关闭统一隐藏普通 PTY。编辑器、transcript、同步历史及临时 Pi 保持现有语义。
- 显式停止、项目/Worktree 删除、退出资源清理仍处理隐藏终端；保留远程托管限制。
- 中英文文案，保持现有样式与架构，无新依赖/IPC/数据库迁移。

## Acceptance Criteria

- [ ] 标签关闭不关闭 PTY、不删除记录/原布局、不卸载 xterm 输出监听；重开 ID 与进程不变。
- [ ] 单/多/深层 Pane、多个 Workspan、最后标签和批量关闭的激活回退正确。
- [ ] 展开/折叠/紧凑侧栏、scope/focus-mode 下归属正确且保留终端可重开。
- [ ] 列表删除停止并移除指定终端，持久化恢复不再出现；删除 Worktree 不泄漏隐藏会话。
- [ ] 本地/WSL/Bash/SSH、失焦/托盘、hook 有无、失效目录沿用既有能力；旧快照默认可见，两条恢复分支保留隐藏状态。
- [ ] 非普通终端关闭与编辑器未保存确认不回归。
- [ ] 聚焦自动测试、TypeScript 与严格架构检查通过；不能执行的实机验证明确记录。
- [ ] 更新 CHANGELOG TEMP 与功能清单，切换双语言实机验证或记录环境限制。
