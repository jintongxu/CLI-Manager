# 全应用主题方案与交互预览

## Goal

提供三套差异化全应用视觉方向及独立交互网页预览；覆盖工作区、文件编辑器、设置、统计，支持深浅色及中英文。不修改生产主题或真实运行状态；选型后再确认实施。

## Requirements

- 独立入口 `design-previews/app-theme/index.html`，零依赖、无 CDN，可直接打开本地 HTML。
- Graphite 石墨钴蓝、Porcelain 暖白墨绿、Midnight 深海青色；三套均支持深浅色、中文/英文、舒适/紧凑。
- 四个完整场景：终端工作区、文件编辑器 Diff、设置、统计。保留项目树、分支、终端会话、底部设置/统计的应用心智模型。
- 支持主题、模式、语言、密度、页面、项目、终端标签、文件、侧栏折叠与模拟设置操作。
- 专业桌面工具视觉：系统字体栈、等宽终端、内联 SVG、清晰的层次、长名称截断、24 小时制。
- 所有数据为模拟；设置只在内存存活；不调用真实进程、网络、存储、通知或文件 API。
- 可见状态反馈、可访问标签、键盘焦点、窄桌面响应式布局。
- 不改生产文件、不安装依赖、不提交；交付记录由主代理处理。

## Acceptance Criteria

- [x] 独立 HTML/CSS/JS 文件，各文件低于 2000 行。
- [x] 3 × 2 × 2 × 2 × 4 = 96 个配置/场景组合通过无依赖渲染 smoke test。
- [x] `node --check` 两个运行脚本通过；模拟交互及输入转义检查通过。
- [x] `npm run check:architecture -- --strict` 零新增违规。
- [ ] 主代理执行真实浏览器验证：1440 默认截图、各主题深浅色四场景、语言/密度、键盘焦点与窄窗口。

## Scope and scenarios

支持展开/折叠侧栏、多模拟项目、多模拟终端、文件选择、对比分栏切换与空输入状态。真实 WSL、SSH、Worktree、Hook、托盘、后台窗口焦点、分屏进程生命周期均不属于此次独立设计预览；界面中这些信息仅为展示数据。
