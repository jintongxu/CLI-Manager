# 当前项目辅助终端

## 需求
主区域使用 Pi Agent 时，在主区域底部打开当前项目的普通 Shell，手动执行测试、构建、Git 等命令。用户批准原侧栏方案后进一步确认改为底部停靠：仅移动辅助终端，文件/Git 等右侧栏不变。

## 验收
- 操作栏保留双语终端入口，可在显示设置关闭；终端位于中央工作区底部，默认约240px，上边缘可拖动并记忆高度，提供收起与最大化/还原，关闭进程独立确认。
- 项目/Worktree 根目录与连接环境明确；不执行项目 CLI 启动命令、不携带对话恢复身份。
- 首次明确打开才创建；切换项目不自动创建新 Shell；同一环境复用已存在终端。
- 不激活、替换主 Pi 会话，不插入当前工作或普通标签。
- 收起/切换上下文保留 PTY 与输出解析器；显式关闭等待后端确认，失败保留可重试。底部终端与右侧页签独立开关，不能抢占文件/Git面板。
- 临时 Shell 不参与重启恢复，实例退出沿现有托管 PTY 事务回收。
- 自动测试覆盖上下文、单飞、迟到创建、关闭失败和显示契约；手工环境未验证须明确说明。

## 场景
焦点在主 Pi/侧栏/其他窗口；主区域分屏及跨工作区切换；侧栏收起/切页签/左右停靠；窗口最小化/托盘；普通项目/Worktree/失效Worktree；本地Shell/WSL/SSH；hook有无；进程自然结束与创建、关闭、退出竞态。无明确项目时显示空状态而非猜目录。当前目录指项目根目录而非追踪每次cd。

## 用户确认：本地干净 pwsh
- 仅侧栏本地创建使用 `pwsh -NoLogo -NoProfile`，跳过用户 profile、shell runtime monitoring 与快速 prompt 脚本；不引入新 shell key、不用嵌套 startupCmd。
- 内部 `CLI_MANAGER_SIDEBAR_CLEAN_PWSH=1` 在 owner 本地创建调用的用户环境展开之后设置；WSL/SSH 不携带该标记。后端解析参数后消耗标记，不导出给子进程命令。
- 普通终端保留原 profile/缓存 prompt/监控启动策略。项目 CLI、恢复身份及扩展不得生成侧栏自动启动命令。
