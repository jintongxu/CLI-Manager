# 需求规格：侧栏伴随式 AI 对话「思考/推理强度」控件重构

## 1. 业务背景与痛点
- 当前侧栏 AI 对话面板（`ChatPanelSurface.tsx`）的推理强度设置是一个紧凑无边框的原生下拉选择器。
- 痛点：缺少视觉边界和图标提示，容易被误认为静态文本，且点击区域小、状态不明显；切换不同档位时没有视觉反馈。

## 2. 交互与视觉规格
1. **胶囊控件外观（Pill）**：
   - 整体为一个带圆角边框、柔和背景的独立可点击胶囊按钮（类似标签/开关）。
   - 左侧带有脑部图标（`Brain`），中间显示「`思考` / `Think`」固定标签以及当前档位名称（`默认` / `低` / `中` / `高`），右侧带有下拉小箭头（`ChevronDown`）。
2. **下拉弹出层**：
   - 点击后展开主题化的 Radix 下拉菜单，选项包含 4 档：默认、低、中、高；当前选中项显示对勾（`Check`）。
   - 展开时箭头旋转 180°。
3. **档位激活态反馈**：
   - 当用户选择「低 / 中 / 高」等具体推理档位时，控件边框和脑图标呈现主强调色（`var(--accent)`），提示当前提问会带有强思考。
   - 当档位为「默认」时，恢复中性弱色背景。
4. **国际化支持**：
   - 新增的前缀词在中英文下分别显示为 `思考` 与 `Think`，各档位文案沿用现有 i18n 字典。

## 3. 验收标准
- 页面渲染正常，深浅色主题下背景与字体对比度合规。
- 键盘操作可用：Tab 可聚焦控件，Enter/Space 可展开下拉，方向键可切换档位。
- 不影响全局快聊（QuickChat）小窗的既有逻辑。
- `npx tsc --noEmit` 与 `npm run check:architecture` 0 报错。
