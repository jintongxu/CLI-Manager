# Scenario Matrix

| 场景维度 | 必须验证 |
|---|---|
| 窗口 | 普通窗口、最大化、全屏 |
| 终端 | 普通 Shell、Pi Agent、Claude/Codex、文件编辑器 |
| Pane | 单 pane、水平分屏、垂直分屏、深层 split |
| 侧栏 | 左停靠、右停靠、折叠、拖拽宽度 |
| 辅助面板 | merged、独立 panel、action rail 显示/隐藏 |
| 背景 | 无背景、工作区背景、终端背景透明 |
| 状态 | hover、focus-visible、selected、disabled、拖拽中 |
| 页面 | 终端、历史、统计、设置、空状态 |
| 主题 | Midnight Aurora、Terminal Acrylic、Clear Focus/其他浅色 |
| 运行数据 | 正式版数据、隔离 preview 数据不交叉 |
