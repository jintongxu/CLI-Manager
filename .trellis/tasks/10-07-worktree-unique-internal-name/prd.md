# Worktree 内部命名避重与显示名称分离

## 用户需求
修复中文任务名隔离打开时 worktree_path_exists；任务名输入框用于显示名称，默认填入本次内部名称，允许修改中文。在下面显示无法修改、可复制的内部名称。普通、分屏、自动隔离和 Git 工作区创建规则一致。

## 用户补充确认（运行验收反馈）
用户确认：所有新建 Worktree 都先填名称，包括自动隔离、始终隔离和分屏；已有 Worktree 内追加终端、普通非隔离终端不弹框。撤回自动策略跳过表单的行为，命名候选保持固定只读。

## 验收
- 显示名称支持中文/英文/混合/数字、同名重复；修改显示名称不修改内部名称。
- 新建的内部名称含随机后缀；开窗初始化一次，再次开窗是新名字。
- 现存目录、分支、缺失目录但有注册、同一分钟创建、共享根目录和多窗口/外部并发占用均安全处理；不删除或复用现存对象。
- 正常创建实际名字与只读预览一致；极少数外部占用时允许自动改名，用户说明清晰，显示名不改变。
- 创建请求重复 guard 保留，成功失败均释放；真实 Git/权限错误不隐藏。
- SQL 保存失败明确报错，后续创建不因残留再撞同名。
- 主仓库与 linked worktree 均支持；WSL/UNC/remote 保持拒绝，不依赖焦点、最小化、Hook、侧栏模式。
- 中英文 label/说明/aria；实际桌面语言切换验证若未执行必须说明。

## 非目标与兼容
不改旧 Worktree 分支或目录、不改数据库结构、不新增依赖、不改 finish/force-delete/依赖安装/PTY。旧字符串入参和 Web 旧 taskName 作为显示名兼容。不开启应用、不擅自同步/提交 Git。
