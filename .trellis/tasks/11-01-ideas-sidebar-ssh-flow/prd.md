# 项目想法极简流、项目树展开丝滑度与SSH文件分屏联动 PRD

## 1. 目标

1. **项目想法（Project Ideas）去标题化极简改造**：
   - 彻底移除强制的“标题”输入框，支持单输入框速记流（类似 Apple Notes / Flomo 灵感速记）。
   - 自动将首行文字提纯为卡片展示标题（超出长度截断），全量内容作为正文，完美兼容底层数据库 `title` / `content` 字段。
   - 支持快捷键 `Ctrl+Enter` / `Cmd+Enter` 极速提交保存。
   - 移除 `disabled={!newTitle.trim() || !newDraft.trim()}` 的双重输入阻断，只要输入框有内容即可保存。

2. **左侧项目栏点击展开丝滑度与性能优化**：
   - 根治展开/折叠项目或分组时的全树重新渲染问题：优化 `TreeContext`，避免 `collapsedIds` 变化穿透全树触发无意义 render。
   - 为项目 Worktree / 终端展开子列表引入平滑 Grid 展开过渡动画（Accordion Transition），消除突兀的 Layout Shift 与白屏跳变。

3. **当前工作模式下 SSH 终端文件面板与标签联动优化**：
   - 当前工作模式下，从 SSH 终端的文件面板打开远程文件时，自动与该 SSH 终端在工作区内**左右分屏（Split Pane）**展示，使终端交互与文件查看并存。
   - 当前工作顶栏标签优化：编辑器标签动态提取当前正在查看的真实文件名（例如 `nginx.conf · SSH: Ubuntu`），而不是空泛的 `文件：SSH: Ubuntu`。
   - 生命周期自愈：当编辑器内所有打开的文件均被关闭时，自动从当前工作移除该编辑器面板并聚焦原 SSH 终端，避免留下空壳面板。

## 2. 场景与约束

- **向下兼容**：已有项目想法数据库无需变更，继续安全读写；老数据正常显示。
- **国际化**：同步更新 `zh-CN` 与 `en-US` 字典，无硬编码。
- **架构约束**：严格遵守手写代码行数限制（单文件不得超过 2000 行），`npm run check:architecture -- --strict` 零超限。
- **测试保护**：更新并补充定向单元测试，保证所有测试通过。

## 3. 验收标准

- [ ] 项目想法弹窗与工具栏只展示一个自适应多行输入框，输入内容按快捷键或点击按钮即可创建，标题自动提取首行。
- [ ] 树节点展开/收起时平滑无掉帧，全树非关联节点不发生冗余重新渲染。
- [ ] 在当前工作中的 SSH 终端打开文件面板点击文件，编辑器与 SSH 终端形成分屏；标签显示当前文件名；所有文件关闭后自动回收编辑器面板。
