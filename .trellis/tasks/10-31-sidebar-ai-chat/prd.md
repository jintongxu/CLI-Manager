# 需求与验收标准：侧栏伴随式 AI 对话面板 (Sidebar AI Chat Companion)

## 一、背景与目标

用户在工作区（普通开发终端、运行中的 pi agent 智能体会话、文件编辑器等）工作时，常会遇到突发灵感、报错卡壳或需要临时请教 AI 的场景。此前必须切换到顶部一级导航的全屏「对话」空间，打断当前工作心流。

本任务在右侧栏增加专属对话按钮与侧栏对话面板：

- **完全复用现有对话配置**：`设置 → 对话模型`（`chat_provider_catalog_list`）中已启用的供应商与模型直接可用，零二次配置。
- **共享同一状态与数据**：基于全局单例 `chatController` 与既有 SQLite 表，侧栏会话与全屏对话空间完全互通。
- **随手体验**：快捷键呼出/收起、浮动/停靠双模式、一键放大到全屏、工作区选中文本一键带入。

## 二、功能范围

### 1. 入口与集成
- 右侧操作栏新增「AI 对话」按钮（`Sparkles` 图标），Tooltip 含 `Alt+C`。
- `TerminalSidePanel` 新增 `"chat"` Tab，与 Stats/Replay/Git/Files/Providers/BTW 平级。
- 「设置 → 侧边栏 → 终端工具栏」新增 `chat` 显隐开关（默认开启）；旧配置由 `migrateTerminalToolbarOrder` 自动补齐排序键。

### 2. 面板能力
- 顶部：历史对话下拉、模型选择器、新建、`⤢` 放大、Pin 模式切换、`✕` 关闭。
- 中部：紧凑消息流（Markdown + 代码高亮）、流式输出、状态与错误码文案、复制、失败重试、自动滚底跟随。
- 底部：自适应高度输入框（Enter 发送 / Shift+Enter 换行 / 输入法安全）、草稿实时保存、停止生成、选中文本胶囊。

### 3. 双模式
- 浮动：`absolute` 覆盖卡片，不改变工作区尺寸。
- 停靠：`TerminalSidePanel` Tab，跟随既有宽度记忆与 dock 侧设置。
- 未启用合并侧边面板（`terminalSidePanelMerged=false`）时自动退化为浮动，避免切到不存在的宿主。

### 4. 快捷键
- `Alt+C` 全局切换显隐（硬编码，见 design.md 取舍）。

## 三、非目标

- 不引入 MCP、联网搜索、文件索引知识库、命令执行等重型机制。
- 不改变既有 BTW（`MessageSquare`）基于会话快照的定向追问功能。
- 不新增 Rust 命令或数据库迁移。

## 四、验收标准

1. 右侧栏出现「AI 对话」按钮，点击可打开/收起对话框面板。
2. 模型下拉完整读取「设置 → 对话模型」的启用项，能正常流式回答。
3. 侧栏聊天持久化到 SQLite；点 `⤢` 能切到全屏对话空间且停留在同一会话。
4. 浮动模式不挤压工作区；Pin 后转为停靠并支持拖拽宽度。
5. 在终端 / pi agent / DOM 文本区划选文本后，面板出现引用胶囊，点击可带入提问。
6. `Alt+C` 可切换显隐；重启后会话记录与草稿不丢失。
7. 中英文文案齐全；`npx tsc --noEmit` 与 `npm run check:architecture` 通过。

## 五、工作区保护

不提交 git、不启动或重启应用进程、不改动既有脏数据（`.workflow/spec-analytics.jsonl` 由知识库工具自身写入）。
