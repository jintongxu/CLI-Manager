# 系统资源面板支持删除终端

在终端内存资源列表中为每项提供删除入口。删除复用现有严格关闭接口 `closeSession(id, true)`，不是隐藏，不删除历史/项目文件。需要危险确认、取消、重复操作保护、失败保留与错误提示，以及中英文支持。定位与删除按钮相互独立。

覆盖本地/WSL/SSH、隐藏终端、分屏、多项目、运行中/已退出及采样失败。确认后重读目标身份；目标消失或不可操作时不得误删。末页删空使用现有分页钳制。

验收：定向行为测试、TypeScript、严格架构检查；真实Tauri/SSH/WSL关闭和语言切换未实测时明确说明。保留SidebarFooter上一需求修改；不自动重启、提交、推送。
